**Test case updates needed**: The `pharmgx-reporter` harness shows a high volume of `incorrect_determinate` findings, indicating its existing test cases may need refinement or expansion to cover more complex diplotype-to-phenotype chains and edge cases. The `bio-orchestrator`'s `unroutable_crash` category suggests a need for additional test cases targeting skill routing failures and prompt-injection resilience.

**New category patterns**: Finding categories like `transcript_selection_error` (in `cvr-variant-identity`) and `criteria_not_machine_parseable` (in `cvr-acmg-correctness`) highlight specific, recurring failure modes that should be formalized into dedicated test cases for those harnesses. The `missing_output` category in `gwas-prs` indicates a need for test cases that validate output generation under various input conditions.

**ROADMAP adjustments**: Given the high `incorrect_determinate` rate in `pharmgx-reporter`, the planned `clinpgx` harness (P1-3) should be prioritized, as it may share underlying logic and its test development could benefit from the same ground-truth sources. The `gwas-prs` harness, already implemented, should be expanded with the planned PRS strand-flip and ancestry transferability tests (P2-8) sooner, given its `missing_output` findings.
