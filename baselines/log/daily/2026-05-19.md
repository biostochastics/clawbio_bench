## Coverage Investigation

### Coverage Gaps
The current suite lacks harnesses for variant-annotation, clinpgx, clinical-trial-finder, target-validation-scorer, genome-compare, methylation-clock, wes-clinical-report, claw-ancestry-pca, gwas-lookup, scrna-orchestrator, rnaseq-de, proteomics-de, and data-extractor as outlined in the ROADMAP.

### Test Case Updates Needed
High counts of `unroutable_crash` (bio-orchestrator), `edge_crash` (equity-scorer), `incorrect_determinate` (pharmgx-reporter), and `missing_output` (gwas-prs) indicate that existing harnesses require additional edge-case and error-handling test cases.

### New Category Patterns
Finding categories such as `snp_invalid` (nutrigx-advisor), `transcript_selection_error` (cvr-variant-identity), and `gene_disease_context_missing` (clinical-variant-reporter) suggest new test cases are needed for input validation, transcript selection logic, and contextual data completeness.

### ROADMAP Adjustments
The existing gwas-prs and clinical-variant-reporter harnesses partially cover P1-4 and P1-1, respectively; priorities should shift toward expanding these harnesses rather than building from scratch. Other planned harnesses (e.g., variant-annotation, clinpgx) remain high-priority gaps.

### Action List
1. Expand clinical-variant-reporter (P1-1) with small unambiguous-subset correctness tests.
2. Build variant-annotation harness (P1-2) for VEP, ClinVar, and gnomAD validation.
3. Build clinpgx harness (P1-3) for CYP2C19, CYP2D6, DPYD, TPMT, HLA-B.
4. Formalize and expand gwas-prs harness (P1-4) to cover strand flips and ancestry transferability.
5. Build clinical-trial-finder harness (P1-5) for FHIR eligibility matching.
