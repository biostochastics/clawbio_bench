## Coverage Investigation

**Coverage gaps**:  
ClawBio skills with no dedicated harness coverage include `variant-annotation`, `clinpgx`, `clinical-trial-finder`, `target-validation-scorer`, `genome-compare`, `methylation-clock`, `wes-clinical-report`, `claw-ancestry-pca`, `gwas-lookup`, `scrna-orchestrator`, `rnaseq-de`, `proteomics-de`, and `data-extractor`. The current test suite covers only 10 of the 23+ skills inventoried in the roadmap.

**Test case updates needed**:  
The `unroutable_crash` category in `bio-orchestrator` and `edge_crash` in `equity-scorer` suggest that test cases for input validation and error handling require expansion to cover more edge conditions. The `incorrect_determinate` findings in `pharmgx-reporter` indicate that ground-truth references for drug-gene interactions may need updates to reflect current PharmGKB/CPIC annotations.

**New category patterns**:  
The presence of `snp_invalid` in `nutrigx-advisor` and `transcript_selection_error` in `cvr-variant-identity` suggests a need for new test cases that validate input sanitization and transcript selection logic. The `missing_output` category in `gwas-prs` points to potential silent failures that warrant dedicated test cases for output generation completeness.

**ROADMAP adjustments**:  
Given that `gwas-prs` is already covered (though with gaps), its priority in the roadmap should shift from initial implementation to expansion—specifically adding strand-flip and ancestry-transferability tests (P2-8). The `clinical-variant-reporter` Phase 2 (P1-1) should be accelerated due to its Tier 1 clinical harm potential and the existing structural foundation. The `clinpgx` harness (P1-3) can reuse infrastructure from `pharmgx-reporter`, potentially lowering its implementation effort.

**Action list** (prioritized):
1. Expand `clinical-variant-reporter` to Phase 2 (P1-1) with small unambiguous-subset correctness tests.
2. Implement `clinpgx` harness (P1-3) leveraging existing `pharmgx-reporter` infrastructure.
3. Add strand-flip and ancestry-transferability test cases to `gwas-prs` (P2-8).
4. Create `variant-annotation` harness (P1-2) for VEP consequence and ClinVar significance validation.
5. Develop `data-extractor` harness (P3-1) to cover structured field extraction from semi-structured inputs.
