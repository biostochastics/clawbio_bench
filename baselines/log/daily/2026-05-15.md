## Coverage Investigation

The `gwas-prs` skill, while having a harness, exhibits a `missing_output` finding category, indicating incomplete test coverage.

**Test case updates needed**  
Specific findings point to required test case expansions:
*   The `unroutable_crash` finding in `bio-orchestrator` suggests a need for test cases involving malformed or unroutable inputs.
*   The `incorrect_indeterminate` finding in `pharmgx-reporter` indicates a requirement for additional test cases around indeterminate result classification.
*   The `susie_inf_est_tausq_ignored` finding in `clawbio-finemapping` points to needed test cases for handling infinite variance estimates in SuSiE.

**New category patterns**  
Emerging failure patterns highlight new testing needs:
*   The `missing_output` category in `gwas-prs` suggests a pattern of silent failures, requiring test cases that explicitly assert output generation.
*   The `transcript_selection_error` in `cvr-variant-identity` indicates a need for test cases that validate transcript selection logic against known correct transcripts.

**ROADMAP adjustments**  
Based on current findings, the following roadmap adjustments are recommended:
*   The `gwas-prs` harness (P1-4) shows a `missing_output` finding, suggesting its planned expansion (P2-8: strand-flip/ancestry tests) should be prioritized earlier.
*   The `clinical-variant-reporter` Phase 2 (P1-1) remains a high priority given existing findings like `gene_disease_context_missing`.
*   The `clinpgx` harness (P1-3) should be prioritized over other P2 items due to direct clinical harm potential and its overlap with existing `pharmgx-reporter` infrastructure.

1.  Expand the `gwas-prs` harness with strand-flip and ancestry transferability tests (P2-8) to address the `missing_output` finding.
